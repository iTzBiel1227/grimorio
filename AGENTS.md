# Grimório — colaboração e GitHub

O usuário autorizou publicar este projeto no repositório público
`https://github.com/iTzBiel1227/grimorio`, com a branch principal `main`,
e manter o GitHub atualizado conforme trabalhamos neste projeto.

- Ao concluir alterações solicitadas pelo usuário, revise os arquivos e execute
  `npm run sync -- "Descrição curta da alteração"` (no PowerShell: `npm.cmd`).
  O comando executa os testes, cria um commit e envia para `origin/main`.
- Esta autorização vale para alterações concluídas no projeto. Não envie trabalho
  incompleto, alterações de terceiros não relacionadas ou tarefas de revisão sem edição.
- Respeite qualquer instrução posterior do usuário para adiar ou evitar um envio.
- Nunca inclua bancos SQLite, contas, sessões, PDFs enviados pelos usuários,
  arquivos `.env`, credenciais, `node_modules` ou backups no Git. Preserve o `.gitignore`.
- Não faça force push nem sobrescreva alterações remotas. Resolva divergências
  preservando o trabalho local e remoto antes de enviar.
- Confirme o resultado do push. Se faltar autenticação ou houver falha de rede,
  informe claramente que as mudanças locais ainda não foram enviadas.
